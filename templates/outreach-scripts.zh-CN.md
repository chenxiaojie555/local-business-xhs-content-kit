# 03 首单获客话术

## 微信首轮

```text
老板你好，我刚看到你家店，产品/环境其实挺适合做小红书同城种草的。

我注意到现在内容有点像“菜单/门店展示”，用户第一眼不太容易知道为什么要收藏、什么时候来、适合谁来。

我这边可以做一个99元试用包：1篇完整小红书笔记 + 3个标题 + 3个封面文案 + 发布建议。你不用先长期合作，先看稿子值不值。
```

## 电话转微信

```text
老板你好，我不是推销平台广告的。我是做小红书内容文案的，刚看了你家店，感觉有几个同城种草角度能写。
你方便加个微信吗？我发你3行诊断，不合适也没关系。
```

## 小红书私信

```text
你好，我看你家店的内容很适合做同城种草，但现在更像产品展示。
我可以先给你做一个很小的试用包：1篇笔记 + 3个标题 + 封面文案，99元，满意再继续。
如果方便，我可以先发你一个免费诊断方向。
```

## 对方问“你是谁”

```text
我是做本地商家内容文案的，不是平台官方，也不卖广告位。
主要帮门店把“硬广介绍”改成用户视角的小红书笔记，比如约会、赶时间、怕踩雷、想省钱、想拍照出片这类场景。
```

## 对方问“能保证效果吗”

```text
不能保证爆文，也不做刷量。
我能保证的是按小红书用户视角帮你把标题、开头、关键词、封面文案和发布节奏做好，让内容比普通硬广更有机会被看懂、被收藏。
```

## 对方觉得99元也贵

```text
理解。那我建议你先不用买套餐。
我可以免费给你一个标题方向：把“产品名+价格”换成“城市/商圈+痛点+场景”，比如“扬州约会别只会去商场，这家小店更适合慢慢坐”。
如果你觉得这个方向有用，再试99元包。
```

## 成交后收资料

```text
收到。我开始做之前，需要你发我这些：
1. 店名和城市商圈
2. 主推产品/服务
3. 想吸引的人群
4. 客单价大概多少
5. 3-5张门店/产品图
6. 有没有不能写、不能夸大的地方

资料齐了我开始算交付时间。
```

## 交付后复购

```text
这版可以先发，建议3天后看浏览、点赞、收藏、评论。
如果收藏少，通常改标题和封面；如果浏览有但没人咨询，通常改开头和评论区钩子。
你要是想继续跑，我建议先做199元三篇包，把3种方向赛马一下。
```
