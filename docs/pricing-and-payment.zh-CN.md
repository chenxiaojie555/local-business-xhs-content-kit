# 02 报价单与收款说明

## 套餐

### A. 29元单条体验

适合先判断素材和合作方式是否匹配。

- 小红书/朋友圈方向草稿：1条
- 标题：1-2个
- 封面文案：1个
- 简短发布建议：1份
- 不含精修图片、不含多轮修改
- 交付时间：资料齐全后24小时内

### B. 99元试用包

适合第一次合作。

- 店铺内容诊断：3-5条
- 小红书完整笔记：1篇
- 标题：3个
- 封面文案：3个
- 关键词/话题：6-10个
- 发布建议：1份
- 交付时间：24小时内

### C. 399元首周获客包

适合本周就想发活动、发新品、发朋友圈成交图的小店。

- 小红书完整笔记：3篇
- 标题：每篇3个
- 封面文案：每篇3个
- 关键词/话题：每篇6-10个
- 7天发布节奏建议
- 朋友圈活动成交图文案：1份
- 私信/评论咨询回复话术：1份
- 1次轻量修改

### D. 699元月度基础包

适合稳定更新。

- 每周3篇，合计12篇/月
- 每周关键词/选题建议
- 每周一次简短数据复盘
- 每月一次内容方向调整
- 不含拍摄、不含投流、不含达人、不含代发

## 收款口径

```text
确认做的话，可以使用双方确认后的付款方式。付款备注：店名 + 套餐。
我收到后开始做，第一版按约定时间发你；如果基础信息不完整，时间从资料补齐后开始算。
```

## 退款口径

```text
如果我还没开始写，可以全额退。
如果已经完成第一版，不支持无理由退款，但可以免费按约定修改一次。
如果是我没有按约定交付，支持退款。
```

## 发票/合同口径

初期个人小额试单可以不开票；如果客户需要正式合同、对公付款或发票，先不要承诺，单独确认能力后再接。

## 支付信息注意事项

陌生客户首单不要直接发送个人支付信息。正式合作、客户明确要求、双方信息确认后，再使用合适的付款方式。
