# 01 商业流程SOP

## 一句话产品

给本地商家做“小红书内容诊断 + 试用笔记包”，帮老板把硬广改成用户愿意看的同城种草内容。

## 标准流程

### 1. 选行业

优先选一个行业连续跑，不要一天换一个方向。推荐顺序：

1. 美容美甲/皮肤管理
2. 宠物店/宠物医院
3. 咖啡甜品/轻餐
4. 写真摄影/婚纱
5. 教培/升学规划

### 2. 找目标商家

每个商家只看5分钟，满足2条就进名单：

- 有线下门店或清楚地址。
- 小红书/抖音/美团/大众点评能搜到。
- 内容像广告：只有门店图、价格、地址，没有用户视角。
- 近30天没更新，或更新但互动很低。
- 店铺客单价较高，能承受99元试单。

### 3. 做3行诊断

给每个商家写一段个性化诊断，不能复制粘贴味太重：

```text
我看了你家账号/店铺，感觉产品本身不错，但现在内容更像菜单展示。
如果改成“同城用户的真实场景”，比如【下雨天/约会/赶时间/怕踩雷】这类切入，搜索和收藏会更自然。
我可以先做一个99元试用包：1篇小红书笔记 + 3个标题 + 封面文案，当天给你看效果稿。
```

### 4. 首次触达

只做一对一，不群发轰炸。每天建议10-30个商家，记录是否回复。

触达渠道优先级：

- 微信：已有老板微信或公众号/店铺留有微信。
- 电话：店铺公开电话，先问是否方便加微信发一份内容诊断。
- 小红书私信：谨慎使用，避免高频重复话术。
- 大众点评/美团：如果有商家联系方式，走公开联系方式。

### 5. 收款

小额试单使用双方确认后的付款方式。收款前先确认：

```text
可以，我这边按99元试用包做。内容包括：1篇完整笔记、3个标题、3个封面文案、1个发布建议。
你付款后把店名、地址、主推产品、你想吸引的客户发我，我今天/明天给第一版。
```

不要在首轮陌生消息里直接发送个人支付信息；正式合作、对公付款或客户明确要求转账时，再单独确认。

### 6. 客户需提供的信息

最低限度：

- 店名
- 城市/商圈
- 主推产品或服务
- 客单价区间
- 目标客户：学生/白领/宝妈/情侣/宠物主人等
- 1-5张门店或产品图
- 禁止夸大的点：例如医疗效果、升学承诺、绝对疗效等

### 7. 交付

99元试用包交付格式：

- 1篇完整小红书笔记
- 3个标题
- 3个封面文案
- 6-10个关键词/话题
- 发布时间建议
- 一句评论区置顶话术

### 8. 复购升级

交付后不要马上求夸，直接给升级路径：

```text
这版你可以先发。发出去3天后看浏览、点赞、收藏、评论，我可以再帮你调一次标题和开头。
如果你想连续做，我建议先跑399元首周获客包；跑顺后再做699元/月的固定内容包。
```

也可以把首周方案直接报成：

```text
如果你想这周就连续发，我建议做399元首周获客包：3条内容 + 1张朋友圈活动图文案 + 7天发布节奏 + 咨询回复话术。这样比单篇更容易看出哪个方向能带来咨询。
```

## 禁止动作

- 不承诺一定爆文、涨粉、成交。
- 不刷赞、不刷评论、不买假粉。
- 不写虚假探店体验。
- 不用客户照片做人身攻击、低俗营销或虚假宣传。
- 不替客户发布违规医疗、教育、金融承诺。
